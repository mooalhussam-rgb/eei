# EEI — Support Excellence Index (Android WebView)

## Build the APK
**Option A – GitHub (no setup):** create a repo, upload this folder's contents, open *Actions → Build APK → Run workflow*, then download `EEI-apk` (contains `app-debug.apk`).

**Option B – Android Studio:** File → Open this folder, wait for Gradle sync, then *Build → Build APK(s)*. Output: `app/build/outputs/apk/debug/app-debug.apk`.

Requires Android 10+ (minSdk 29). Install the APK (allow "install unknown apps").
